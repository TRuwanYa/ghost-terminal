# 👻 Ghost Terminal

Ghost Terminal is an evolving, Python-based conversational AI chatbot designed to understand user intent, recognize emotions, remember user information, and provide personalized responses through a terminal interface.

## Features

**Currently implemented:**
- Basic intent recognition using Sentence Transformers and machine learning
- Persistent user memory using SQLite
- User and Ghost name management
- Intent classification with confidence-based rejection
- Training, validation, and unit testing

**Planned features:**
- Emotion recognition
- Context-aware conversations
- Personalized responses based on user emotions
- Expanded conversational memory
- A consistent Ghost personality and response system

## Technologies

- Python
- Sentence Transformers (all-MiniLM-L6-v2)
- Scikit-learn
- SQLite
- NumPy

## Project Status

🚧 **Under Active Development**

Ghost Terminal is being developed incrementally, starting with memory management and intent recognition, followed by emotion detection and more advanced conversational capabilities.
